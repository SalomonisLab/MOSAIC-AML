Reading the board

Each sample is first run through the control gate — a healthy-vs-diseased call. A "control" reads as no mutation; a "diseased" specimen proceeds to mutation calling.

Each mutation prediction shows a model score from the deployed combiner (per-modality linSVM fused with optimized per-mutation modality weights) — not a literal probability. The raw score is over-confident, so the chance ✓ column is the held-out-calibrated empirical chance the call is correct. AUC is that mutation's sealed held-out reliability; a call below the 0.65 floor is flagged ⚠ low-confidence (treat as a lead, confirm by sequencing).

Expand a row for the modalities that drove the call. ᴿᴺᴬ-tagged modalities (ADT, GRN, Lipid, Metabolite) are imputed from RNA — RNA-conditioned views, weighted but not independent evidence.

Validation samples show ✓ / ✗ = predicted call vs the known label. Decision-support only.
